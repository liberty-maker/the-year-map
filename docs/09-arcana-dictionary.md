# Arcana Dictionary

The Arcana Dictionary is the first interpretation layer for The Year Map engine.

It contains original, concise app language for the 22 arcana values used by the calculation modules. The content is not copied source text and is intentionally brief so it can support early UI cards, AI Guide prompts, and PDF report sections without becoming deterministic or overwhelming.

## Content Principles

Each arcana entry includes:

- title;
- core meaning;
- light expression;
- shadow reflection;
- guiding question;
- suggested action.

The tone is premium, clear, psychologically safe, and non-deterministic. The dictionary avoids fortune telling and avoids presenting any calculated value as a fixed outcome.

## UI Cards

The future app can use dictionary entries to render compact cards for matrix, year, health, month, and day sections. Because each field is short, the same content can work in dashboard summaries, detail drawers, and report previews.

## AI Guide

The AI Guide can use dictionary meanings as trusted interpretation context. It should combine deterministic profile values with dictionary language instead of inventing new meanings or recalculating formulas.

## PDF Reports

PDF report generation can reuse the same dictionary entries for concise section summaries, appendix references, and personal reflection prompts.

## Future Expansion

The dictionary can later expand into richer PRO content, including:

- films and cultural references;
- gifts and strengths;
- style cues;
- reflective practices;
- deeper relationship and career prompts;
- premium long-form meanings.

Future expansions should remain original, clearly separated from formulas, and safe for wellness-oriented self-discovery.
