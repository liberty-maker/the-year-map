# Arcana Dictionary

The Arcana Dictionary is the first interpretation layer for the product.

It maps reduced 1–22 energy values to concise original meanings. The language is intentionally short, non-deterministic, and suitable for UI cards, AI context, and report summaries.

## Current content

Each arcana entry includes:

- number;
- title;
- keywords;
- light expression;
- shadow expression.

## Future expansion

Later versions can add:

- long-form interpretations;
- role-specific meanings;
- relationship meanings;
- year meanings;
- health-map meanings;
- films, gifts, and lifestyle associations;
- localized content.
