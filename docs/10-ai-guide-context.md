# AI Guide Context

The AI Guide Context prepares deterministic product data for future AI responses.

The AI layer should not invent calculations. It should consume this structured context and explain it in clear human language.

## Included context

- subject metadata;
- selected dominant matrix energies;
- selected year matrix themes;
- health-map zones;
- month themes;
- guardrails.

## Guardrails

The AI Guide must treat the data as symbolic self-reflection, not medical, legal, financial, or psychological diagnosis.
