# Year Map Profile

The Year Map Profile is the product-facing composition layer.

It combines:

- base matrix;
- year matrix;
- health map;
- month energies.

The profile allows downstream surfaces to consume one stable structure instead of recalculating or assembling separate modules.

## Consumers

Future consumers include:

- mobile app screens;
- web app screens;
- AI guide context;
- PDF report data;
- professional client tools.
